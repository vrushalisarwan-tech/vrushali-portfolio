# Vrushali Rajesh Sarwan — Portfolio

Premium recruiter-first portfolio for Learning Delivery, L&D Operations, Facilitation, Analytics and AI-enabled learning.

## Stack
- Next.js 16.4
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Phosphor Icons
- Roboto

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Content source
Professional experience, outcomes, competencies, projects, certifications, education, awards and research are based on the supplied 2026 Learning Delivery / TLO / LDO resume material. The experience section uses organization marks sourced from public web locations, with an in-UI fallback for unavailable remote images.

## Main files
- `app/components/portfolio.tsx` — page UI and interactions
- `app/data/portfolio.ts` — resume-derived content
- `app/globals.css` — responsive visual system and animations
- `public/resumes/` — supplied resume PDFs
- `public/logos/` — local logo assets/fallbacks
